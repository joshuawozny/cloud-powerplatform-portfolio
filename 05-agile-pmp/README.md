# Agile & Project Management

## 📌 Overview

This section documents Agile delivery artifacts and PMP-aligned project management practices applied across portfolio projects. Content demonstrates the ability to plan, track, and document technical work using both iterative Agile methodologies and structured PMBOK-aligned frameworks — a capability increasingly expected at the Senior and Lead levels in cloud and platform engineering roles.

Artifacts in this section are drawn directly from the portfolio's own development lifecycle — sprint plans, retrospectives, and project documentation that governed the build-out of the projects in this repo — as well as purpose-built case studies aligned to the PMP exam track.

This section is in early development, with content planned for addition as the MS in Information Technology program reaches completion and PMP eligibility is established.

---

## 📂 Planned Content

### 1. Portfolio Sprint Documentation
Agile artifacts covering the iterative development of this portfolio itself — sprint plans, backlog items, retrospectives, and velocity tracking. Demonstrates applied Agile practice on a real, version-controlled project rather than a synthetic scenario.

### 2. NYC311 Platform — Project Documentation
Project-level documentation for the NYC311 Fabric Data Platform, reframed through a PMP lens: scope definition, stakeholder identification, risk register, and a work breakdown structure. Shows how engineering work maps to formal PM deliverables.

### 3. Hybrid Agile / PMBOK Case Study
A documented case study applying a hybrid Agile/PMBOK approach to a realistic enterprise scenario — combining sprint-based delivery with project charter, schedule baseline, and change control documentation. Aligned to PMI's hybrid delivery guidance.

### 4. Agile Tooling Demonstration
Board configurations, workflow definitions, and reporting artifacts from Azure DevOps Boards or equivalent tooling. Covers backlog management, sprint planning, burndown charts, and team velocity reporting.
